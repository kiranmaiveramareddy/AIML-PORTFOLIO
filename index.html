AI projects from my coursework

My current coursework piece: a side-by-side look at the algorithms behind modern AI, and what each one is good for.

Machine learning portfolio artifact

Machine learning algorithms: a visual framework

Goal
Show how the main machine learning algorithms differ by learning style and by where they are used: tabular data, computer vision, NLP and generative AI. I also wanted real examples so each one is easy to picture.
How I built it
I picked 11 algorithms, sorted them by how they learn, and tagged each with its application domains, a real-world use case and a plain-language explanation of how it works. I then laid them out as one comparison chart.
Tools
Course readings on AI, ML, deep learning and GenAI, HTML and CSS for the chart
Why it matters
Choosing the right algorithm is half the job. The tabular models here fit the fraud, churn and risk problems I see in BFSI and e-commerce, while the language and generative models cover assistants and content tools in media.

The framework

Algorithms are grouped by how they learn, then tagged by the kind of data they work best with. Read across a row to see what an algorithm does, and down a column to see which ones compete for the same job.

Supervised learningLearns from labeled examples
Linear regressionTabularForecasting sales, estimating home pricesFits the straight line that keeps the gap between predictions and real values as small as possible.
Decision treeTabularApproving or declining a loan applicationAsks a series of yes-or-no questions about the data and follows the answers down to a decision.
Random forestTabularSpotting fraudulent transactions, predicting customer churnBuilds many decision trees on different slices of the data and lets them vote, which cancels out single-tree mistakes.
Gradient boostingTabularCredit risk scoring, ranking search resultsAdds small trees one at a time, each one fixing the errors the previous trees left behind.
Support vector machineTabularNLPSpam filtering, text classificationFinds the boundary that separates two classes with the widest possible safety margin.
Convolutional neural network (CNN)Computer visionImage classification, defect detection, face recognitionSlides small filters across an image to pick up edges and shapes, then stacks them into higher-level features.
Unsupervised learningFinds structure in unlabeled data
K-means clusteringTabularGrouping customers into segmentsPlaces a set number of centers in the data and assigns every point to its nearest one, adjusting until the groups settle.
Principal component analysis (PCA)TabularComputer visionShrinking large datasets, compressing images, visualizing patternsRe-expresses the data along the few directions that capture the most variation, so you keep the signal and drop the clutter.
Generative adversarial network (GAN)Generative AIComputer visionCreating realistic synthetic images and dataTwo networks compete: one generates fakes, the other tries to catch them, and both improve until the fakes look real.
Diffusion modelGenerative AIComputer visionImage generation such as Stable DiffusionLearns to remove noise a little at a time, so it can start from pure noise and end up with a new image.
Self-supervised learningLearns from unlabeled data by predicting parts of it
Transformer (BERT, GPT)NLPGenerative AIChat assistants, sentiment analysis, summarizing and writing textUses attention to weigh how every word relates to every other word, then learns by predicting missing or next words.

A note on classification: models like GPT learn from unlabeled text, so they are not supervised in the strict sense. I gave them their own group, self-supervised, because they sit between the two classic types. Many of them are later fine-tuned with labeled examples.
